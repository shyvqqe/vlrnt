# Overwolf — локальный отслеживатель результатов Valorant

Это **не обычный exe**. Это пример приложения Overwolf Native (HTML+JavaScript), использующего **официальный Overwolf Game Events Provider**. Оно работает только пока включён ПК, запущен клиент Overwolf и события Valorant доступны. На Render его запускать нельзя.

## Главное ограничение установки

По документации Overwolf для загрузки собственной `unpacked extension` нужен **разрешённый (whitelisted) аккаунт разработчика**. Подать заявку можно по официальной процедуре Overwolf. С 1 ноября 2026 Overwolf объявил, что одобряет только приложения с их монетизацией. Поэтому установка этого прототипа может оказаться недоступна для личного проекта. Никакого способа обхода ограничений здесь нет.

Документация:
- https://dev.overwolf.com/ow-native/getting-started/onboarding-resources/setting-up-dev-environment/
- https://dev.overwolf.com/ow-native/live-game-data-gep/supported-games/valorant/
- https://dev.overwolf.com/ow-native/reference/games/events/

## Подключение

1. Настрой `bot/` на Render. Для существующего домена можно использовать `https://vlrnt.onrender.com`. `GET /health` должен возвращать `OK`.
2. В Render → Environment создай `BRIDGE_TOKEN` (случайная строка от 32 символов), открой Telegram-бота и отправь `/start`.
3. Установи официальный Overwolf: https://www.overwolf.com/ и войди в свою учётную запись.
4. Когда есть статус разрешённого разработчика, открой Overwolf → **Settings / About → Development Options → Load unpacked extension**, укажи **именно папку `overwolf/`**, где лежит `manifest.json`.
5. Запусти установленное приложение **Valorant Telegram Loss Alerts** через Overwolf. В окне будет два поля:
   - **Адрес Render**: `https://vlrnt.onrender.com` (без `/api/match` и без `/health`)
   - **BRIDGE_TOKEN**: **тот же случайный секрет**, что в Environment на Render.
6. Нажми **Сохранить**, затем **Проверить соединение**. В журнале должно быть `Соединение с Render и BRIDGE_TOKEN работают.`
7. В Overwolf включи автозапуск клиента с Windows, если нужно. Манифест приложения содержит `launch_events` для Valorant, чтобы автоматически запустить отслеживатель вместе с игрой.
8. Запусти Valorant и сыграй матч. В журнале Overwolf должно появиться `События Valorant подключены`, затем `Матч закончился` и `Матч передан`. При проигрыше бот отправит личное уведомление.

## Что именно отправляется

Приложение видит событие `match_outcome` (победа/проигрыш/ничья), событие `match_end`, карту, игровой режим, счёт по раундам и, если доступны, KDA и агента. Оно отправляет **ВСЕ исходы** серверу, чтобы победа сбрасывала серию. **В Telegram отображаются только поражения.** Ни один запрос в Telegram-канал не выполняется этим приложением.

Если событие окончания/результата не пришло, отправлять догадку нельзя. Отдельные режимы, в том числе custom/training, имеют ограничения Overwolf. Приложение не воспроизводит историю старых матчей: оно получает только события во время работы.

HS считается, только если доступны `round_report` **по всем сыгранным раундам**. Если это условие не выполнено, HS не показывается, чтобы не вводить в заблуждение. ACS и изменение RR по Overwolf не гарантированы и намеренно опущены.

## Что при отключённом интернете

- События записываются в очередь `localStorage` этого приложения.
- Приложение повторяет отправку примерно каждые 30 секунд, пока работает.
- Параметр `match_id` и список уже отправленных ID не дают снова отправить тот же матч при обычном перезапуске приложения.
- Повторы на сервере также отсекаются через SQLite.
- Если Overwolf/Valorant был закрыт и матч не отслеживался, восстановить его из прошлого без другого источника нельзя.

## Диагностика

- `Overwolf API недоступен` — запустили HTML в браузере, а не через Overwolf.
- `События не подключены` — проверь запущенный Valorant и статус Game Events Provider.
- `HTTP 401` — проверь совпадение `BRIDGE_TOKEN`.
- `Нет сети / Render спит` — очередь сохраняется; по следующей попытке запрос повторится.
- Если часть статистики отсутствует, это означает, что Overwolf не прислал соответствующее событие. Не подставляй случайные числа.

Секрет сохраняется **в локальном хранилище приложения Overwolf**; не передавай папку профиля Overwolf и данные токена посторонним людям. Токен бота `TELEGRAM_TOKEN` не нужен и не должен вводиться в Overwolf.
